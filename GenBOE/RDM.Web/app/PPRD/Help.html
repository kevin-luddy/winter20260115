Edit PPR&D Help
Expand a Section:
Click on the icon to expand a collapsed Section.
Collapse a Section:
Click on the icon to collapse an expanded Section.
Add a Section:
To create a parent Section, click on the Section icon next to a Section's title.
 
To create a child Section, click on the Sub-section icon next to a Section's title.
Add Content:
To create a new Content inside a Section, click on the Content icon next to a Section's title.
Edit an item (Section/Content):
To edit an item, click on the icon next to the item's title.
Delete an item (Section/Content):
To delete an item, click on the icon next to the item's title.
Move an item (Section/Content):
Items can be moved via drag and drop by dragging when the Move cursor is shown. To move an item to be inside of a different Section that currently has no sub-sections, drop the item on the Section's title.
Saving changes:
Click on the or the button to save your changes. Clicking on the Save & Continue does not release your lock for PPR&D, and allows for additional changes.
