Importing Project Map does a complete replacement of the existing Project Map data. Start by exporting the existing Project Map data defined in genBOE to get the column definitions and the existing data. Then you modify the data and finally import the updated information.
Step 1: Export the existing Project Map Data
Start by exporting the existing Project Map Data. This file has the correct column headings and all of the current Project Map data. Then you modify the data and finally import the updated information.
Export existing Project Map data
Step 2: Modify the existing Project Map Data
  • If you are only going to add new Project Map data, then leave all of the existing data in the spreadsheet.
  • Add data for new Project Map rows.
  • The header row should not be modified.
  • The following columns are required: Activity ID, Activity Name, Resource, Cost Center, Start Date, End Date, WBS Number, WBS Element Title, CLIN
Step 3: Import the Project Map data
Select the file to import and then click the Import button.
